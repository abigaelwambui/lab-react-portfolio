# Portfli

### Build. Showcase. Grow.

Portfli is a personal portfolio platform designed to help individuals showcase their skills, experiences, and projects in one place. It provides a simple and accessible way to present your work, tell your story, and create a professional online presence.

## Features

- **Personal Profile:** Introduce yourself through an About Me section.
- **Personal Information:** Display relevant details such as your name, profession, location, and contact information.
- **Project Showcase:** Add and display projects with descriptions and images.
- **Project Management:** Add and remove projects from your portfolio.
- **Responsive Design:** Browse the portfolio on different screen sizes.
- **Contact Section:** Make it easier for visitors to get in touch.

## Technologies Used

- React – Building the user interface.
- JavaScript – Application logic and functionality.
- Bootstrap – Styling and responsive layouts.
- CSS – Custom styling.
- HTML – Structuring the application.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone git@github.com:abigaelwambui/lab-react-portfolio.git
```

### 2. Navigate to the project directory

```bash
cd portfli
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

*Note: The commands above assume your project uses Vite. Check your `package.json` for the appropriate start script if you're using a different setup.*
